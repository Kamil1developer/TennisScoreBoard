# TennisScoreBoard

**TennisScoreBoard** — Java Web-приложение для ведения счёта в теннисном матче.

Проект реализован без Spring Framework: основная цель — показать работу классического Java Web Stack через **Servlets, JSP/JSTL, Hibernate, H2, Maven** и ручную организацию слоёв приложения.

## Возможности

- создание нового матча между двумя игроками;
- валидация имён игроков;
- ведение текущего счёта матча;
- поддержка стандартной логики теннисного счёта: `0`, `15`, `30`, `40`, `AD`;
- обработка `deuce` и преимущества игрока;
- подсчёт геймов и сетов;
- запуск тай-брейка при счёте `6:6` по геймам;
- определение победителя матча;
- сохранение завершённых матчей;
- просмотр списка завершённых матчей;
- фильтрация матчей по имени игрока;
- пагинация списка матчей;
- unit-тесты для логики начисления очков.

## Архитектура проекта

Проект построен в стиле классического MVC-приложения с разделением ответственности между слоями.

```text
src/main/java
├── bootstrap       # инициализация приложения и контейнеров зависимостей
├── dao             # доступ к базе данных
├── dto             # DTO и View DTO для передачи данных между слоями
├── entity          # Hibernate/JPA сущности
├── exceptions      # пользовательские исключения
├── filter          # servlet-фильтры
├── infrastructure  # контейнеры DAO/Service и инфраструктурные классы
├── matches         # модель текущего матча
├── scores          # доменная модель счёта
├── service         # бизнес-логика приложения
├── servlet         # HTTP-контроллеры
├── storages        # in-memory хранилище текущих матчей
└── validator       # валидация входных данных
```

### Основные слои

**Servlet layer**  
Принимает HTTP-запросы, получает параметры из формы, вызывает сервисы и выбирает JSP-страницу для отображения результата.

**Service layer**  
Содержит бизнес-сценарии приложения: создание матча, начисление очков, завершение матча, сохранение результата, получение списка матчей.

**DAO layer**  
Отвечает только за работу с базой данных и изолирует Hibernate-код от бизнес-логики.

**Domain layer**  
Хранит правила предметной области: счёт игрока, геймы, сеты, тай-брейк и состояние текущего матча.

**View DTO layer**  
Используется для передачи подготовленных данных на JSP-страницы, чтобы не отдавать сущности базы данных напрямую во view.

## Страницы приложения

| URL | Назначение |
|---|---|
| `/` | главная страница приложения |
| `/new-match` | форма создания нового матча |
| `/match-score?uuid={match_id}` | страница текущего матча |
| `/matches` | список завершённых матчей |

## Модель данных

В проекте используются две основные сущности:

### `Player`

Хранит данные игрока.

```text
Players
- id
- name
```

### `Match`

Хранит завершённый матч.

```text
Matches
- id
- Player1
- Player2
- Winner
```

Текущие матчи хранятся в памяти приложения по `UUID`. После завершения матча результат сохраняется в базу данных.

## Правила подсчёта очков

Приложение реализует базовую логику одиночного теннисного матча:

- очки внутри гейма идут в порядке `0 → 15 → 30 → 40`;
- если игрок выигрывает очко после `40`, а у соперника меньше `40`, игрок выигрывает гейм;
- при счёте `40:40` следующий выигранный розыгрыш даёт преимущество `AD`;
- если игрок с преимуществом выигрывает следующий розыгрыш, он выигрывает гейм;
- если соперник отыгрывает преимущество, счёт возвращается к `40:40`;
- при счёте `6:6` по геймам начинается тай-брейк;
- тай-брейк выигрывается при достижении минимум 7 очков и разнице минимум в 2 очка;
- матч завершается, когда один из игроков выигрывает 2 сета.

## Запуск проекта

### Требования

Перед запуском должны быть установлены:

- JDK 21+
- Apache Maven
- Apache Tomcat 10+

### Сборка проекта

```bash
git clone https://github.com/Kamil1developer/TennisScoreBoard.git
cd TennisScoreBoard
mvn clean package
```

После сборки `.war`-файл будет находиться в директории:

```text
target/TennisScoreBoard.war
```

### Запуск через Tomcat

1. Скопировать `target/TennisScoreBoard.war` в директорию `webapps` установленного Tomcat.
2. Запустить Tomcat.
3. Открыть приложение в браузере:

```text
http://localhost:8080/TennisScoreBoard/
```

### Запуск через IntelliJ IDEA

1. Открыть проект как Maven-проект.
2. Настроить локальный Tomcat.
3. Добавить артефакт `TennisScoreBoard:war exploded`.
4. Указать application context:

```text
/TennisScoreBoard
```

5. Запустить конфигурацию Tomcat.

## Тестирование

Для запуска unit-тестов:

```bash
mvn test
```

Тесты покрывают часть логики начисления очков, в том числе:

- выигрыш гейма после `40`;
- переход к преимуществу после `deuce`;
- сброс очков после выигранного гейма;
- запуск тай-брейка при счёте `6:6`.

## Особенности реализации

- Проект не использует Spring, поэтому зависимости собираются вручную через собственные контейнеры.
- `AppContextListener` создаёт Hibernate `SessionFactory`, DAO и сервисы при старте приложения.
- Активные матчи хранятся в in-memory storage по `UUID`.
- Завершённые матчи сохраняются через Hibernate.
- Для JSP используются подготовленные View DTO, а не JPA-сущности напрямую.
- H2 используется как учебная база данных для локальной разработки.
